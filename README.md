# Portfólio técnico — SRE sênior UNIX

Acervo técnico pesquisável sobre UNIX, AIX, Linux e engenharia de confiabilidade. Contém 130 referências em 21 assuntos, incluindo 25 conteúdos de SRE sênior.

## Conteúdo

- SLOs, orçamento de erro e observabilidade.
- Diagnóstico de performance em AIX, PowerVM e Linux.
- Resposta a incidentes, postmortems e recuperação.
- Capacidade, sobrecarga e alta disponibilidade.
- Automação com Ansible e mudanças em lotes.
- DB2, TSM, SAP HANA, WebSphere e Spectrum Scale.

## Consulta local

Requer Python 3 apenas para servir os arquivos estáticos:

```sh
python3 -m http.server 8000
```

Abra http://localhost:8000 no navegador. A busca e os filtros funcionam sem servidor de aplicação ou banco de dados.

## Estrutura

- `index.html`: interface.
- `style.css`: estilos responsivos.
- `app.js`: busca, filtros e referências.
- `data.json`: acervo anonimizado.
- `sources.json`: origem da consolidação.

Exemplos didáticos não representam projetos ou experiências profissionais realizadas. Comandos devem ser ajustados e validados antes do uso em um ambiente real.

O conteúdo novo inclui links para documentação oficial. Referências não são reproduções integrais dos documentos de origem.
